# Pipit Anime Finder 

**Pipit Anime Finder** adalah aplikasi pencarian dan eksplorasi anime yang dirancang untuk memudahkan pengguna menemukan informasi lengkap mengenai berbagai judul anime favorit mereka.

---

##  Fitur Utama

- **Pencarian Anime (Search Bar):** Cari judul anime favorit secara langsung melalui kolom pencarian.
- **Filter Berdasarkan Genre:** Jelajahi anime berdasarkan kategori/genre favorit seperti *Action*, *Adventure*, *Avant Garde*, *Comedy*, *Drama*, *Boys Love*, dan lainnya.
- **Daftar & Katalog Anime:** Menampilkan daftar anime lengkap dengan cover, tipe (TV/Movie), dan rating.
- **Halaman Detail Anime:** Informasi rinci mencakup:
  - Poster/Gambar Anime
  - Judul Anime
  - Genre
  - Rating
  - Jumlah Episode
  - Status Penayangan (misal: *Finished Airing*)
  - Sinopsis Lengkap
